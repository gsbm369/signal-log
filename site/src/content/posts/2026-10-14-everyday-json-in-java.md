JSON is ubiquitous in modern software, and many use cases are just too small to justify adding external dependencies. To address these everyday use cases, a new JEP proposes a simple, incubating API for parsing, navigating, and generating JSON documents-both for Java developers and for the JDK itself. While the Java ecosystem offers many libraries with JSON-processing capabilities, this built-in API is not intended to replace them, but rather to offer a low-friction option when an external library would be unnecessary or impractical. In this talk, we will show how Data-Oriented Programming helps simplify the API, discuss its intended use cases, outline the design trade-offs, and demonstrate its capabilities.
