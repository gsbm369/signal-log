Interacting with foreign libraries from Java has never been easier, thanks to the Foreign Function Memory (FFM) API. But interacting with entire foreign language runtimes, like JavaScript or Python, remains hard. Project Detroit paves a new way forward: instead of implementing bespoke language runtimes from scratch, it leverages FFM to embed industry-standard native runtimes like V8 and CPython in the safety and comfort of your Java application.
