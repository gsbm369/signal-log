A Reddit user was able to get Nintendo's "Animal Crossing: New Horizons" and "Super Mario Odyssey" to run natively on the Apple TV 4K , continuing a string of ports made possible with the use of AI (via Engadget ). TVPort , Reddit user FloatingFalafel's open-source project, is a fork of the nxnative toolkit used to recompile Switch and Switch 2 games for the Apple TV using a Mac. It was built using Claude Opus 5.5. "Super Mario Odyssey" runs at 60fps according to FloatingFalafel, and "Animal Crossing" runs at 30fps. Other games haven't been tested, but the creator says people are welcome to use the open-source software to get other games to run. Game files are not included, and users will need to supply files from their own game cartridges, which requires a modified Nintendo Switch.
