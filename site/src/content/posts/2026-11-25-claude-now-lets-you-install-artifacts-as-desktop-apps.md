Anthropic has released a new feature for Claude that allows users to install artifacts as desktop apps on macOS and Windows. Artifacts are documents, designs, dashboards, and interactive tools that Claude creates in a panel alongside your chat, where you can view and edit them. When you ask Claude to create an artifact, you can now click "Install as app" in the Share menu, after which you'll be able to launch it in its own dedicated app window and see it in the Dock. Artifact-based apps don't need to be packaged or signed, but they do need a permission level to be set. Choosing Default permissions means they can only do what they'd be able to do in a browser, while giving them higher App permissions means they can do things like create always-on-top windows, listen for global keyboard shortcuts, and send notifications.
